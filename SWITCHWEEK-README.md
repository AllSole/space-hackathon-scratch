# SwitchWeek — Hackathon MVP

A static browser MVP for a telecom app mechanic that gives young customers one useful, user-chosen plan boost every week.

## Run

```bash
python3 -m http.server 8080
```
Open `http://localhost:8080`.

## Demo loop
1. Pick Study, Go, or Share.
2. Review the weekly entitlement.
3. Activate it.
4. See the active state and next weekly reset.

No real customer data, accounts, payments, APIs, or AI are used. All data is mock/demo data.
